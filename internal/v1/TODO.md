# Glyphflow v1 implementation roadmap

This roadmap implements the approved v1 execution, authentication, authorization, and recovery design.

All rows remain unchecked until implementation and verification are complete.

Implement one row at a time. Test it, commit it, and record the commit hash and result in the last column.

## Project outcome

Glyphflow will schedule durable logical runs and execute signed orders on authorized remote runners.

PostgreSQL will remain the control-plane source of truth. Runner SQLite will preserve accepted orders and unpublished events.

NATS JetStream will provide at-least-once delivery. Database constraints and idempotent consumers will make duplicate delivery safe.

Users will sign in with a password or generic OIDC. Database-backed roles and permissions will protect each API action.
