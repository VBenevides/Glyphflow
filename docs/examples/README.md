# Examples

These examples are organized by user goal. Each flow has its own README and a
`screenshots/` directory containing numbered images for the important steps
and results. All example data is fake.

The repository images are captures from the local Glyphflow console in white
mode. The records shown in them use fake names, credentials, hosts, commands,
and identifiers.

- [Create and inspect a first task](first-task/README.md)
- [Schedule recurring work](scheduled-task/README.md)
- [Place work on the right runner](runner-placement/README.md)
- [Handle a failed run](failed-run/README.md)
- [Manage access](access-control/README.md)

Use a new local database for the examples. Do not use production data,
credentials, hostnames, or identifiers in the text or screenshots.
